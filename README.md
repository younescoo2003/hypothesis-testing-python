## 📊 Project Overview
A complete demonstration of statistical hypothesis testing using Python, including t-tests, chi-square tests, effect sizes, and visualizations.

## 🎯 What This Project Does
- Generates synthetic A/B test data
- Performs two-sample t-tests
- Conducts chi-square tests for independence
- Calculates effect sizes (Cohen's d)
- Creates publication-ready visualizations

## 🛠️ Technologies Used
- Python 3.8+
- NumPy & Pandas (Data manipulation)
- SciPy (Statistical tests)
- Matplotlib & Seaborn (Visualizations)
